Urban Company Service-Ops Diagnostic & AI-Augmented Reporting Toolkit

This project is a complete analytics workflow based on Urban Company-style service data. I worked through the project in four parts, using the same data from start to finish.
Part A – Data & SQL:I created the SQLite database using Python, checked the data, cleaned the partner records and generated the final `city_category_summary.csv`.
Part B – Spreadsheet: I imported the final CSV into Excel/Google Sheets, used VLOOKUP, SUMIFS and a revenue pivot table, and reconciled the totals with the SQL results.
Part C – Tableau Dashboard:I created a Tableau Public dashboard showing total revenue, bookings, SLA breach rate, category revenue, city performance and city-to-category analysis.
Part D – AI Reporting: I prepared reporting prompts and an escalation-agent specification using the reconciled project data.

Key Results

* Total Revenue: ₹1,047,973
* Total Bookings: 600
* SLA Breaches: 79
* SLA Breach Rate: 13.2%
